## Функциональность

### Реализовано
- Класс `Product`: Моделирует товар с атрибутами: название, описание, цена, количество.
- Класс `Category`: Моделирует категорию товаров, содержит список товаров. Автоматически ведёт подсчёт категорий и товаров.
- Загрузка данных: Функции `load_json` и `create_objects_from_json` для инициализации объектов из JSON-файла.
- Метод `Category.add_product`: добавляет объект `Product` в приватный список товаров категории и увеличивает общий счётчик товаров.

### Приватные атрибуты и свойства
**Приватные атрибуты и свойства:**
- `Product` защищает атрибут цены через приватное поле `__price`. Доступ к нему предоставляется через свойство `price` с геттером и сеттером.
- `Category` хранит список товаров в приватном поле `__products`. Свойство `products` возвращает строку в формате: `"Название, X руб. Остаток: Y шт.\n"`.

**Валидация данных:**
- Сеттер `Product.price` проверяет, что цена не равна нулю и не отрицательна. При нарушении выводится предупреждение, и цена не изменяется.
- Если новая цена ниже текущей, сеттер запрашивает подтверждение пользователя через ввод `Y`. Без подтверждения цена остаётся прежней.

**Метод создания товара:**
- `Product.new_product()` — класс-метод, создающий товар из словаря. При передаче списка существующих товаров объединяет дубликаты по имени: складывает количество и выбирает максимальную цену. При неверной структуре словаря (отсутствующие или лишние ключи) метод выбрасывает `ValueError` с сообщением "Ошибка в структуре данных продукта".

## Использование

```python
from src.product import Product
from src.category import Category
from src.utils import load_json, create_objects_from_json

# Создание товаров вручную
phone = Product("iPhone", "Смартфон", 999.99, 10)
laptop = Product("MacBook", "Ноутбук", 1999.99, 5)

# Создание категории
electronics = Category("Электроника", "Техника", [phone, laptop])

print(electronics.name)  # Электроника
print(electronics.products)
# Вывод:
# iPhone, 999.99 руб. Остаток: 10 шт.
# MacBook, 1999.99 руб. Остаток: 5 шт.

# Загрузка из JSON
data = load_json("data/products.json")
categories = create_objects_from_json(data)

# Демонстрация свойства Product.price
product = Product("Товар", "...", 100.0, 5)
print(product.price)  # 100.0 (геттер)
product.price = 150.0  # сеттер (без подтверждения, так как цена увеличивается)
product.price = -10    # Выведет: "Цена не должна быть нулевая или отрицательная"
# product.price = 50   # Раскомментируйте для интерактивного режима: запросит подтверждение через input('Y')

# Демонстрация свойства Category.products
category = Category("Категория", "...", [product])
print(category.products)  # "Товар, 150.0 руб. Остаток: 5 шт.\n"

# Метод Product.new_product с объединением дубликатов
existing = [Product("Телефон", "...", 500.0, 2)]
new_data = {"name": "Телефон", "description": "...", "price": 550.0, "quantity": 3}
updated = Product.new_product(new_data, existing)
print(f"Обновлённый товар: количество={updated.quantity}, цена={updated.price}")
# Обновлённый товар: количество=5, цена=550.0

# Добавление товара в категорию
new_product = Product("Наушники", "...", 200.0, 8)
electronics.add_product(new_product)
print(electronics.products)  # Будет выведен обновлённый список
```

## Тестирование

Проект покрыт юнит-тестами Pytest. Для их запуска выполните команды:
```
# Запуск всех тестов
pytest

# Запуск с отчетом о покрытии в консоли
pytest --cov=src

# Генерация HTML отчета о покрытии (будет создана папка htmlcov/)
pytest --cov=src --cov-report=html
```
